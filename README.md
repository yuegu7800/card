# NEON WRAITH

Interactive 3D holographic collectible card built with Three.js.

## Live demo

https://yuegu7800.github.io/card/

Drag to rotate, use the mouse wheel to zoom, switch between the front and back, and adjust parallax depth and foil intensity from the control panel.

## Card

- Rarity: SSR
- Finish: silver foil + holographic
- Edition: No.001
- Artwork: original cyberpunk heroine

The browser viewer reproduces the Blender material behavior in GLSL. The real-time result and Blender render are designed to be visually close, but are not pixel-identical.
